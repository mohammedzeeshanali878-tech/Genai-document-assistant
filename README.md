# AI Smart Document Assistant (GenAI Project)

## Overview
This project is a Generative AI-based application that allows users to upload PDF documents and interact with them using natural language queries.

## Features
- PDF Question Answering
- Document Summarization
- Semantic Search using Vector Embeddings
- Conversational AI Interface

## Tech Stack
- Python
- Streamlit
- LangChain
- OpenAI API
- FAISS

## Use Case
Useful in healthcare RCM, finance, and business analytics for extracting insights from reports and documents.

## How to Run
1. Install dependencies
2. Add your OpenAI API key
3. Run: streamlit run app.py
